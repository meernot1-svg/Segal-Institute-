     5→
     6→## Design Plan (one-time, committed)
     7→- **Type roles:** Fraunces (display/headings — characterful soft serif, editorial-premium feel) + Hanken Grotesk (body — clean, highly legible, not the default Inter/system pairing).
     8→- **Color tokens (6):**
     9→  1. Navy `#1E2A52` — primary
    10→  2. Ink `#0B1220` — deep text / footer
    11→  3. Emerald `#10B981` — accent / focus ring
    12→  4. Cream `#F7F4EE` — warm section surfaces (instead of generic grey)
    13→  5. Slate `#5B6478` — secondary text
    14→  6. White `#FFFFFF` — surfaces
    15→- **Layout concept:** "Editorial, calm, premium — warm cream section surfaces with deep-navy type and a single emerald accent; generous spacing; content-led pages with one bold visual moment per screen."
    16→- **Avoids:** ALL-CAPS eyebrows over every heading, arrow-tacked links, identical rounded cards everywhere, purposeless gradients, fake "01/02/03" numbering.
    17→
    18→## Architecture decisions
    19→- Auth: custom (scrypt password hashing + HMAC-signed session cookie), no external auth dep. `role` on Profile (student|admin).
    20→- Middleware guards protected routes (cookie presence); server components/API verify the signed token.
    21→- Verb forms stored with accepted-answer arrays (JSON strings in SQLite) so multiple valid spellings score correctly.
    22→- Seed: large curated set of real English verbs (irregular + regular with correct +ed/+d/double-consonant/y→ied rules). meaning_language defaults to `en` (Sindhi meanings arrive via Phase 4 PDF import).
    23→- AI: Phase 3 only; mock-mode ready. Phase 1 has no AI features.
